REPOMenu
by Nitro70

A mod menu for R.E.P.O. Press F2 in game to open it (you can change the key in the Settings tab).

STATUS
  This is an early build and has NOT been tested in game yet. Expect rough edges. Use it in
  singleplayer or in private lobbies with friends who are happy to have it on.

WHAT IT DOES
  - Self:      god, can't-die, auto-heal, max health, infinite stamina, no-ragdoll
  - Movement:  speed, jump, extra air jumps, fly / noclip, long reach, strong grab and throw
  - ESP:       enemies (+health), valuables (+$ value), items, players, extraction points, carts,
               boxes, tracers, distance and value filters, and reveal valuables on the map
  - Visuals:   fullbright, no fog, field of view, the game's own freecam, hide HUD
  - Teleport:  to your aim, the truck, extraction, the best valuable, players, and saved spots
  - Character: live cosmetics (wardrobe, colours, rainbow, unlock all, outfit copy/paste, tokens)
  - Host:      players (heal / revive / move / upgrade), enemies (kill / freeze / spawn),
               spawner (items / valuables / enemies), world (money, extraction, valuable prices,
               levels). The HOST tabs work only when you host the lobby (or play alone); the game
               ignores them from a guest.

HOW IT KNOWS WHAT TO LIST
  Items, valuables, enemies, levels, upgrades, cosmetics and colours are read from the game while it
  runs, so game updates and other mods' content show up on their own. If a game update changes
  something a card uses, that card turns itself off and says so; the rest keeps working.

SETTINGS
  BepInEx\config\com.nitro70.repomenu.cfg (menu key, size, favourites, binds). Cheats always start
  switched off.

UNINSTALL
  Run the installer again and press Uninstall. It removes only what it installed.
